# KRECHET Mini App — demo

Это демонстрационная версия интерфейса без сервера, VPN-доступа и реальных платежей.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

После этого Vite покажет локальный адрес.

## Сборка

```bash
npm run build
```

Готовая папка для публикации появится в `dist/`.

## Что уже есть

- Главное меню KRECHET.
- Анимированный процедурный 3D-кречет на Three.js.
- Горный фон.
- Профиль.
- Тарифы: 199 / 549 / 999 / 1 799 ₽.
- Поддержка.
- Настройки.
- Инструкция.
- Информация.
- Экран устройств: 2 места бесплатно, дальше 59 ₽/мес (пока только визуальная демонстрация).
- Внутренние разделы с кнопкой «Назад».
- Адаптация под телефон.

## Что подключается позже

Сервер, Telegram Mini App API, реальные платежи, база пользователей, подписки, приглашения устройств и выдача VPN-доступа.

3D-кречет сейчас процедурный, поэтому отдельная `.glb` модель не нужна для запуска демо.
